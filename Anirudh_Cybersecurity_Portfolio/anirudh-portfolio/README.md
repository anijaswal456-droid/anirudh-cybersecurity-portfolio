# Anirudh Jaswal — Cybersecurity Portfolio

Full-stack portfolio using HTML/CSS/JS + Node.js/Express.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Backend
- `GET /api/health` health check.
- `POST /api/contact` accepts name, email and message and stores them in `messages.json`.

## Deploy
The app can be deployed to Render, Railway, Fly.io or another Node.js host. Set the start command to `npm start`.

## Before public deployment
Replace/add your real LinkedIn and GitHub links, add verified projects, and use a persistent database/email service for contact messages rather than local `messages.json`.
